      • For identity objects (SerializableResource, Node and Function), the reference is returned.

    StaticcreateSignature

    • createSignature(_object: Record<string, unknown>): string

      Creates a shallow structural signature string for the given object. The signature encodes each Object.getOwnPropertyNames own property name and its corresponding typeof value. Unlike the normal typeof behavior, when a property value is null, the signature will contain undefined instead of object.

      Parameters

      • _object: Record<string, unknown>

      Returns string

      Example

      Controller.createSignature({ x: 1, y: 2 });
      // → "x:number|y:number"

      Controller.createSignature({ color: { r: 1 } });
      // → "color:object"

      Controller.createSignature({ ref: null });
      // → "ref:undefined"

    • updateUserInterfaceStructure(
          _mutable: object,
          _details: Details,
          _mutator: Mutator,
          _parentMutable?: object,
          _parentKey?: string,
      ): void

      Ensures that a Details element matches the structure of the given FudgeCore.Mutator. Performs a shallow structural integrity check by comparing the element’s cached signature with the mutator’s signature. If they differ, the element’s content is rebuilt to reflect the new structure.

      Parameters

      • _mutable: object

        The original mutable object represented in the UI.

      • _details: Details

        The Details element displaying the data.

      • _mutator: Mutator

        The mutator object describing the current structure and values.

      • Optional_parentMutable: object

        (optional) The parent mutable object if nested.

      • Optional_parentKey: string

        (optional) The key referencing this mutable within its parent.
